# kanibar

A WaniKani widget for the [Omarchy](https://omarchy.org) bar (Quickshell).

- **In the bar:** how many reviews are waiting and how many lessons are available today.
- **Click to open a panel with:** upcoming reviews, level progress, and more.

It uses the official [WaniKani API v2](https://docs.api.wanikani.com/). You need a read-only personal access token from your WaniKani account settings.

> Status: early development.
